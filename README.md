# Switch2EV

A BSc web development project focused on electric vehicle adoption, user-friendly web design and providing clear information about electric vehicles, charging and available incentives.

## Project Overview

Switch2EV was created as part of my BSc (Hons) Cyber Security & Networks studies.

The aim of the project was to design and develop a multi-page website that helps users understand electric vehicles, their benefits, charging options and available incentives.

The project also allowed me to develop practical skills in front-end web development, page structure, responsive design, JavaScript validation and user-focused website design.

## Main Features

- Multi-page website structure
- Electric vehicle information
- EV charging information
- Government incentive information
- Contact page
- Login page
- Form validation
- Responsive page styling
- Consistent navigation and visual design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Website Pages

- `index.html` — Home page
- `about.html` — About the project

- `incentives.html` — Incentives and support
